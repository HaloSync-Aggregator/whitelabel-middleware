[3. Apidog OpenAPI Sync Script: scripts/sync-openapi.mjs]

3-1. Create a new `scripts/sync-openapi.mjs` file.

Requirements:

- ESM (`.mjs`), targeting Node 18+.
- Execution sequence:
  1) Read `process.env.APIDOG_PROJECT_ID`, `APIDOG_ACCESS_TOKEN`, `APIDOG_API_VERSION`.
  2) If any of these are missing:
     - Clearly print to stderr which environment variable is empty and exit with `process.exit(1)`.
  3) Call the Apidog Export OpenAPI API:
     - URL:
       `https://api.apidog.com/v1/projects/${projectId}/export-openapi?locale=ko-KR`
     - Method: `POST`
     - Headers:
       - `X-Apidog-Api-Version: ${apiVersion}`
       - `Authorization: Bearer ${token}`
       - `Content-Type: application/json`
     - Body (JSON):
       {
         "scope": { "type": "ALL" },
         "options": {
           "includeApidogExtensionProperties": false,
           "addFoldersToTags": false
         },
         "oasVersion": "3.0.1",
         "exportFormat": "JSON"
       }
  4) If the response status is not 2xx:
     - Log the status code, statusText, and part of the response body, then exit.
  5) On success:
     - Parse the response JSON and save it to `spec/polarhub.openapi.json`.
     - Create the `spec` directory if it does not exist.
  6) Output a brief log to the console for success/failure.

3-2. Add or update the following entry in the `scripts` section of `package.json`:

"scripts": {
  // ... existing scripts
  "sync:openapi": "node -r dotenv/config scripts/sync-openapi.mjs"
}

Note: Do NOT run `npm run sync:openapi` in this session.
Just explain that "running this command later will save the OpenAPI spec to spec/polarhub.openapi.json".
