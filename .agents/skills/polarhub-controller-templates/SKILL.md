# PolarHub Controller Templates

Complete code templates for reference when writing NestJS Controllers.

---

## 0. Route Prefix Rules (CRITICAL)

> **MUST**: All Controller routes must use the `polarhub/` prefix. The global prefix `middleware` is set via `app.setGlobalPrefix('middleware')` in `main.ts`, so the final URL is `/middleware/polarhub/{api-name}`.

```typescript
// CORRECT - polarhub/ prefix required
@Controller('polarhub/air-shopping')
@Controller('polarhub/offer-price')
@Controller('polarhub/order')
@Controller('polarhub/order-change')
@Controller('polarhub/order-reshop')
@Controller('polarhub/order-quote')
@Controller('polarhub/seat-availability')
@Controller('polarhub/service-list')

// WRONG - do NOT include global prefix in @Controller (setGlobalPrefix handles it)
@Controller('middleware/polarhub/air-shopping')  // Prohibited! Global prefix is auto-applied
@Controller('air-shopping')                      // Prohibited! Missing polarhub/ prefix
```

**Route Naming Conventions:**
| API | Route |
|-----|-------|
| AirShopping | `polarhub/air-shopping` |
| OfferPrice | `polarhub/offer-price` |
| Order (Create/Retrieve/Cancel) | `polarhub/order` |
| OrderChange | `polarhub/order-change` |
| OrderReshop | `polarhub/order-reshop` |
| OrderQuote | `polarhub/order-quote` |
| SeatAvailability | `polarhub/seat-availability` |
| ServiceList | `polarhub/service-list` |

## 2. Basic Controller Structure

> **Note**: `PolarHubExceptionFilter` is registered as a global exception filter in `main.ts` and automatically catches all `PolarHubError` exceptions thrown by the service/client layer. Therefore, controllers do **not** need try/catch blocks for PolarHub errors. Simply call the service method directly and let any errors propagate to the global filter.

```typescript
@ApiTags('api-name')  // Swagger group
@Controller('polarhub/api-name')
export class YourApiController {
  private readonly logger = new Logger(YourApiController.name);

  constructor(private readonly polarHubService: PolarHubService) {}

  @Post()
  @HttpCode(HttpStatus.OK)  // Return 200 (query-like despite being POST)
  @ApiOperation({
    summary: 'API summary (one line)',
    description: `Detailed description.
- TransactionID is generated by FE and passed through
- Additional notes...`,
  })
  @ApiBody({ type: YourRequestDto })
  @ApiResponse({ status: 200, description: 'Success description' })
  @ApiResponse({ status: 400, description: 'Invalid request' })
  @ApiResponse({ status: 401, description: 'Authentication failed' })
  async methodName(
    @Body() request: YourRequestDto,
    @Res({ passthrough: true }) res: Response,
  ): Promise<unknown> {
    // 1. Request logging
    this.logger.log({
      message: 'API request received',
      transactionId: request.transactionId,
      // Additional context...
    });

    // 2. Service call
    const response = await this.polarHubService.yourMethod({
      transactionId: request.transactionId,
      sender: request.sender ? { /* transform */ } : undefined,
      // Additional parameters...
    });

    // 3. Set response header
    res.setHeader('X-Transaction-Id', request.transactionId);

    // 4. Return raw response (no transformation!)
    return response;
  }
}
```

## 3. Pre-Booking Controller Templates

### 3.1 AirShopping Controller

```typescript
@ApiTags('air-shopping')
@Controller('polarhub/air-shopping')
export class AirShoppingController {
  private readonly logger = new Logger(AirShoppingController.name);

  constructor(private readonly polarHubService: PolarHubService) {}

  @Post()
  @HttpCode(HttpStatus.OK)
  @ApiOperation({
    summary: 'Search for available flights',
    description: `PRE-BOOKING flow starting point.
- TransactionID is provided by FE (pass-through principle)
- Must reuse same TransactionID for OfferPrice and OrderCreate`,
  })
  @ApiBody({ type: AirShoppingRequestDto })
  @ApiResponse({
    status: 200,
    description: 'Flight search results - returns raw PolarHub response',
  })
  @ApiResponse({ status: 400, description: 'Invalid request' })
  @ApiResponse({ status: 401, description: 'Authentication failed' })
  async searchFlights(
    @Body() request: AirShoppingRequestDto,
    @Res({ passthrough: true }) res: Response,
  ): Promise<unknown> {
    this.logger.log({
      message: 'AirShopping request received',
      transactionId: request.transactionId,
      routes: request.originDestList.length,
      passengers: request.passengers.reduce((sum, p) => sum + p.count, 0),
      hasSender: !!request.sender,
    });

    const response = await this.polarHubService.searchFlights({
      transactionId: request.transactionId,
      sender: request.sender
        ? {
            travelAgency: {
              agencyId: request.sender.travelAgency.agencyId,
              siteCode: request.sender.travelAgency.siteCode,
              agencyName: request.sender.travelAgency.agencyName,
              contactInfoRefId: request.sender.travelAgency.contactInfoRefId,
            },
          }
        : undefined,
      originDestList: request.originDestList,
      passengers: request.passengers,
      cabin: request.cabin,
      airlinePreference: request.airlinePreference,
      directOnly: request.directOnly,
    });

    res.setHeader('X-Transaction-Id', request.transactionId);
    return response;
  }
}
```

@Controller('polarhub/order')
export class OrderController {
  private readonly logger = new Logger(OrderController.name);

  constructor(private readonly polarHubService: PolarHubService) {}

  /**
   * Create a new order (OrderCreate)
   */
  @Post()
  @HttpCode(HttpStatus.OK)
  @ApiOperation({
    summary: 'Create a new booking order',
    description: `Final step of PRE-BOOKING flow.
- WF_PB_DEFERRED: Without paymentList (hold)
- WF_PB_IMMEDIATE: With paymentList (immediate ticketing)`,
  })
  @ApiBody({ type: OrderCreateRequestDto })
  @ApiResponse({
    status: 200,
    description: 'Order created - returns raw PolarHub response',
  })
  @ApiResponse({ status: 400, description: 'Invalid request' })
  @ApiResponse({ status: 401, description: 'Authentication failed' })
  async createOrder(
    @Body() request: OrderCreateRequestDto,
    @Res({ passthrough: true }) res: Response,
  ): Promise<unknown> {
    this.logger.log({
      message: 'OrderCreate request received',
      transactionId: request.transactionId,
      paxCount: request.paxList.length,
      hasPayment: !!request.paymentList,
      workflow: request.paymentList ? 'WF_PB_IMMEDIATE' : 'WF_PB_DEFERRED',
    });

    const response = await this.polarHubService.createOrder({
      transactionId: request.transactionId,
      sender: this.transformSender(request.sender),
      orders: request.orders,
      paxList: request.paxList,
      contactInfoList: request.contactInfoList,
      paymentList: request.paymentList,
    });

    res.setHeader('X-Transaction-Id', request.transactionId);
    return response;
  }

  /**
   * Retrieve order details (OrderRetrieve)
   */
  @Post('retrieve')
  @HttpCode(HttpStatus.OK)
  @ApiOperation({
    summary: 'Retrieve order details',
    description: `POST-BOOKING flow starting point.
- Use new TransactionID (generated by FE)`,
  })
  @ApiBody({ type: OrderRetrieveRequestDto })
  @ApiResponse({
    status: 200,
    description: 'Order details - returns raw PolarHub response',
  })
  @ApiResponse({ status: 404, description: 'Order not found' })
  async getOrder(
    @Body() request: OrderRetrieveRequestDto,
    @Res({ passthrough: true }) res: Response,
  ): Promise<unknown> {
    this.logger.log({
      message: 'OrderRetrieve request received',
      transactionId: request.transactionId,
      orderId: request.orderId,
    });

    const response = await this.polarHubService.getOrder({
      transactionId: request.transactionId,
      sender: this.transformSender(request.sender),
      orderId: request.orderId,
    });

    res.setHeader('X-Transaction-Id', request.transactionId);
    return response;
  }

  /**
   * Cancel order (OrderCancel)
   */
  @Post('cancel')
  @HttpCode(HttpStatus.OK)
  @ApiOperation({
    summary: 'Cancel an order',
    description: `Use same TransactionID from OrderRetrieve.`,
  })
  @ApiBody({ type: OrderCancelRequestDto })
  @ApiResponse({
    status: 200,
    description: 'Order cancelled - returns raw PolarHub response',
  })
  @ApiResponse({ status: 400, description: 'Invalid request' })
  @ApiResponse({ status: 404, description: 'Order not found' })

    @Body() request: OrderCancelRequestDto,

    });

    return response;
  }

  /**
   * Sender transformation helper (deduplication)
   */
  private transformSender(sender?: SenderDto) {
    if (!sender) return undefined;
    return {
      travelAgency: {
        agencyId: sender.travelAgency.agencyId,
        siteCode: sender.travelAgency.siteCode,
        agencyName: sender.travelAgency.agencyName,
        contactInfoRefId: sender.travelAgency.contactInfoRefId,

## 4. Post-Booking Controller Templates

### 4.1 OrderChange Controller

```typescript
@ApiTags('order-change')
@Controller('polarhub/order-change')
export class OrderChangeController {
  private readonly logger = new Logger(OrderChangeController.name);

  constructor(private readonly polarHubService: PolarHubService) {}

  @Post()
  @HttpCode(HttpStatus.OK)
  @ApiOperation({
    summary: 'Modify a booking order',
    description: `Supports 7 change types:
- AcceptSelectedQuotedOfferList: Seat/service changes
- AcceptOrderItemList: Hold confirmation
- AcceptRepricedOrder: Itinerary changes (Hold)
- UpdatePax: Passenger info changes
- UpdatePax + ReasonCode:DIV: PNR split
- AcceptChange: OCN acceptance`,
  })
  @ApiBody({ type: OrderChangeRequestDto })
  @ApiResponse({ status: 200, description: 'Order changed successfully' })
  @ApiResponse({ status: 400, description: 'Invalid request' })
  @ApiResponse({ status: 500, description: 'Internal server error' })
  async changeOrder(
    @Body() request: OrderChangeRequestDto,
    @Res({ passthrough: true }) res: Response,
  ): Promise<unknown> {
    // Log change type
    const changeType = this.getChangeType(request.changeOrderChoice);

    this.logger.log({
      message: 'OrderChange request received',
      transactionId: request.transactionId,
      orderId: request.orderId,
      changeType,
      reasonCode: request.reasonCode,
      hasPaxList: !!request.paxList,
      hasPayment: !!request.paymentList,
      hasContactInfo: !!request.contactInfoList,
    });

    const result = await this.polarHubService.changeOrder({
      transactionId: request.transactionId,
      sender: this.transformSender(request.sender),
      orderId: request.orderId,
      changeOrderChoice: request.changeOrderChoice,
      reasonCode: request.reasonCode,
      paxList: request.paxList,
      paymentList: this.transformPaymentList(request.paymentList),  // CRITICAL: Transformation required!
      contactInfoList: request.contactInfoList,
    });

    res.setHeader('X-Transaction-Id', result.transactionId);
    return result.response;
  }

  private getChangeType(choice: any): string {
    if (choice.acceptSelectedQuotedOfferList) return 'AcceptSelectedQuotedOfferList';
    if (choice.acceptOrderItemList) return 'AcceptOrderItemList';
    if (choice.acceptRepricedOrder) return 'AcceptRepricedOrder';
    if (choice.updatePax) return 'UpdatePax';
    if (choice.acceptChange) return 'AcceptChange';
    return 'Unknown';
  }

  private transformSender(sender?: SenderDto) {
    if (!sender) return undefined;
    return {
      travelAgency: {
        agencyId: sender.travelAgency.agencyId,
        siteCode: sender.travelAgency.siteCode,
        agencyName: sender.travelAgency.agencyName,
        contactInfoRefId: sender.travelAgency.contactInfoRefId,
      },
    };
  }

  /**
   * PaymentList transformation (CRITICAL)
   * Converts the simplified type field in the DTO to the Service's paymentMethod object
   *
   * MUST: Set appropriate paymentMethod based on type
   * - Cash → cash: { cashPaymentInd: true }
   * - Ag → agentDeposit: { agentDepositId: '' }
   * - Card → card: { ... } (extend when card details are needed)
   */
  private transformPaymentList(paymentList?: PaymentDto[]) {
    if (!paymentList) return undefined;

    return paymentList.map((p) => ({
      paymentMethod: {
        cash: p.type === 'Cash' ? { cashPaymentInd: true } : undefined,
        agentDeposit: p.type === 'Ag' ? { agentDepositId: '' } : undefined,
        // Card requires card details, implement after DTO extension
      },
      amount: {
        currencyCode: p.curCode,
        amount: p.amount,
      },
      orderItemId: p.orderItemId,
      offerItemId: p.offerItemId,
      paxRefId: p.paxRefId,
    }));
  }
}
```

## 5. Module Registration Pattern

```typescript
// polarhub.module.ts
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import { PolarHubService } from './polarhub.service';
import { PolarHubClient } from './client';

// Controllers
import { AirShoppingController } from './controllers/air-shopping.controller';
import { OfferPriceController } from './controllers/offer-price.controller';
import { OrderController } from './controllers/order.controller';
import { OrderChangeController } from './controllers/order-change.controller';
import { OrderReshopController } from './controllers/order-reshop.controller';
import { OrderQuoteController } from './controllers/order-quote.controller';
import { ServiceListController } from './controllers/service-list.controller';
import { SeatAvailabilityController } from './controllers/seat-availability.controller';

@Module({
  imports: [ConfigModule],
  controllers: [
    AirShoppingController,
    OfferPriceController,
    OrderController,
    OrderChangeController,
    OrderReshopController,
    OrderQuoteController,
    ServiceListController,
    SeatAvailabilityController,
  ],
  providers: [PolarHubService, PolarHubClient],
  exports: [PolarHubService],
})
export class PolarHubModule {}
```

## 6. Logging Patterns

### 6.1 Request Logging (Recommended)

```typescript
this.logger.log({
  message: 'API request received',
  transactionId: request.transactionId,
  // API-specific context
  orderId: request.orderId,            // OrderRetrieve, OrderChange
  changeType: 'UpdatePax',             // OrderChange
  workflow: 'WF_PB_IMMEDIATE',         // OrderCreate
  hasSender: !!request.sender,
  hasPayment: !!request.paymentList,
});
```

### 6.2 Error Logging (Recommended)

```typescript
this.logger.error({
  message: 'API request failed',
  transactionId: request.transactionId,
  error: error.message,
  code: error.code,
});
```

## 7. Controller Checklist

### Before Implementation

- [ ] Verify corresponding DTO class exists
- [ ] Verify corresponding Service method exists
- [ ] Determine API path (`polarhub/{api-name}`)

### During Implementation

- [ ] Set `@ApiTags`
- [ ] Set `@Controller` path
- [ ] Use `@Post` or `@Post('action')` (GET is prohibited!)
- [ ] Set `@HttpCode(HttpStatus.OK)`
- [ ] Write `@ApiOperation` summary/description
- [ ] Set `@ApiBody({ type: RequestDto })`
- [ ] Write `@ApiResponse` for success/failure cases
- [ ] Add logging (include transactionId)
- [ ] Add Sender transformation logic
- [ ] Set transactionId in Response Header
- [ ] Return raw response (no transformation!)
- [ ] Do NOT add try/catch for PolarHub errors -- `PolarHubExceptionFilter` handles them globally
- [ ] Verify `X-Tide-Tenant-Id` header is present in outbound requests (auto-added by auth layer)

### After Implementation

- [ ] Register Controller in Module
- [ ] Verify in Swagger UI
- [ ] No TypeScript compilation errors
