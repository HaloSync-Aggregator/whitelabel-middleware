# OrderCancel API Guide

The OrderCancel API is used for **booking cancellation and refunds**.

## Supported Workflows

| Workflow ID | Description | Phase | Preceding API |
|-------------|-------------|-------|---------------|
| `WF_HELD_CANCEL` | Hold booking cancellation | Post-Held | OrderRetrieve |
| `WF_TKT_REFUND` | Post-ticketed refund | Post-Ticketed | OrderRetrieve → OrderReshop |

---

## Request Structure by Workflow

### 1. Hold Booking Cancellation (WF_HELD_CANCEL)

Can be cancelled directly after OrderRetrieve:

```typescript
// OrderRetrieve → OrderCancel
{
  "Query": {
    "OrderID": "ORDER_ID_TO_CANCEL"
  }
}
```

### 2. Post-Ticketed Refund (WF_TKT_REFUND)

Retrieve refund quote via OrderReshop, then cancel:

```typescript
// Step 1: Retrieve refund quote via OrderReshop
{
  "Query": {
    "OrderID": "ORDER_ID",
    "UpdateOrder": {
      "CancelOrderRefID": {
        "OrderID": "ORDER_ID"
      }
    }
  }
}

// Step 2: Execute refund via OrderCancel
{
  "Query": {
    "OrderID": "ORDER_ID",
    "RefundQuoteID": "from_order_reshop"  // RefundQuoteID from OrderReshop response
  }
}
```

## Response Structure

### Successful Cancellation
```typescript
interface OrderCancelResponse {
  ResultMessage: {
    Code: "0";  // Success
    Message: "Order cancelled successfully";
  };
  Order: {
    OrderID: string;
    OrderStatus: "CANCELLED";
  };
  RefundInfo?: {  // When refund applies
    RefundAmount: {
      Amount: number;
      CurrencyCode: string;
    };
    RefundMethod: string;
  };
}
```

### Failed Cancellation
```typescript
interface OrderCancelErrorResponse {
  ResultMessage: {
    Code: string;  // Not "0"
    Message: string;
    MessageDetail?: string;
  };
}

// Common error codes
// - 50201: Already cancelled
// - 50202: Cancellation not allowed in current status
// - 50203: Cancellation deadline exceeded
```

## HELD vs TICKETED Differences

### HELD Cancellation (Simple)
```typescript
// Can cancel directly, no refund information
OrderRetrieve → OrderCancel

// API call
{
  "Query": {
    "OrderID": "ORDER_ID"
  }
}
```

### TICKETED Refund (Complex)
```typescript
// 1. Retrieve refund quote (OrderReshop)
// 2. Execute refund (OrderCancel)

// Step 1: OrderReshop
{
  "Query": {
    "OrderID": "ORDER_ID",
    "UpdateOrder": {
      "CancelOrderRefID": { "OrderID": "ORDER_ID" }
    }
  }
}

// Step 1 Response
{
  "RefundQuote": {
    "RefundQuoteID": "RQ_123456",
    "RefundAmount": { "Amount": 750000, "CurrencyCode": "KRW" },
    "Penalty": { "Amount": 100000, "CurrencyCode": "KRW" }
  }
}

// Step 2: OrderCancel
{
  "Query": {
    "OrderID": "ORDER_ID",
    "RefundQuoteID": "RQ_123456"
  }
}
```

## DTO Structure (NestJS)

```typescript
export class OrderCancelRequestDto {
  @IsString() transactionId: string;
  @IsString() orderId: string;
  @IsOptional() @IsString() refundQuoteId?: string;  // For refund cases
}

export class RefundInfoDto {
  @ApiProperty() refundAmount: AmountDto;
  @ApiProperty() penalty?: AmountDto;
  @ApiProperty() refundMethod: string;
}

export class OrderCancelResponseDto {
  @ApiProperty() transactionId: string;
  @ApiProperty() order: any;
  @ApiProperty() refundInfo?: RefundInfoDto;
}
```

## Important Notes

### Cancellation Deadline Check
```typescript
// Cancellation deadlines by airline (examples)
const cancellationDeadlines = {
  SQ: '24 hours before departure',
  AY: '3 hours before departure',
  BA: 'Free cancellation within 24 hours of booking',
};
```

### Partial Cancellation Not Supported
```typescript
// Cannot cancel only some passengers → Split PNR first, then cancel
// WF_HELD_SPLIT → WF_HELD_CANCEL
```

### Refund Fees
```typescript
// Check in OrderReshop response
const penalty = response.RefundQuote.Penalty?.Amount || 0;
const netRefund = response.RefundQuote.RefundAmount.Amount - penalty;
```

### Transaction ID Management (Pass-through Principle)
```typescript
// Generated by FE; middleware only passes through!
// ✅ FE responsibility - Maintain same ID within Post-Booking session
const txnId = crypto.randomUUID().replace(/-/g, '');  // Generated by FE
OrderRetrieve(txnId) → OrderReshop(txnId) → OrderCancel(txnId);

// ❌ Do not generate in middleware
const txnId = generateTransactionId();  // Strictly prohibited!
```
