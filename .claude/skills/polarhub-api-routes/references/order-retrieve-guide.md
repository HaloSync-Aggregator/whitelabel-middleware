# OrderRetrieve API Guide

The OrderRetrieve API is the **starting point for all Post-Booking workflows**.

## Supported Workflows

| Workflow ID | Description | Phase | Role |
|-------------|-------------|-------|------|
| `WF_HELD_SEAT` | Hold seat change | Post-Held | Starting point |
| `WF_HELD_SERVICE` | Hold service addition | Post-Held | Starting point |
| `WF_HELD_CONFIRM` | Booking confirmation (ticketing) | Post-Held | Starting point |
| `WF_HELD_CANCEL` | Hold cancellation | Post-Held | Starting point |
| `WF_HELD_ITIN` | Hold itinerary change | Post-Held | Starting point |
| `WF_HELD_PAX` | Passenger info change | Post-Held | Starting point |
| `WF_HELD_SPLIT` | PNR split | Post-Held | Starting point |
| `WF_TKT_SEAT` | Post-ticketed seat change | Post-Ticketed | Starting point |
| `WF_TKT_SERVICE` | Post-ticketed service addition | Post-Ticketed | Starting point |
| `WF_TKT_VOLCHANGE` | Voluntary itinerary change | Post-Ticketed | Starting point |
| `WF_TKT_REFUND` | Refund | Post-Ticketed | Starting point |
| `WF_TKT_OCN` | Involuntary change acceptance | Post-Ticketed | Starting point |

## Middleware API (Frontend → Middleware)

**Endpoint**: `POST /middleware/polarhub/order/retrieve`

```typescript
// Request Body
{
  "transactionId": "4ba5a0b50d2c45b3b5eb343b57ba8897",  // Generated by FE (required!)
  "orderId": "ORD-SQ-12345678"
}

// Response: Raw PolarHub response
// Same transactionId returned via X-Transaction-Id header
```

**CRITICAL - TransactionID Pass-through:**
- TransactionID is **generated by FE** and passed through
- The middleware does not generate it, only **passes it through (pass-through)**
- The **same TransactionID is used** across all APIs within a Post-Booking session

## PolarHub API (Middleware → PolarHub)

```typescript
{
  "Query": {
    "OrderID": "ORDER_ID_FROM_CREATE"
  }
}
```

**Important**: A **new Transaction ID must be generated by FE** when starting a Post-Booking session!

```typescript
// CRITICAL: TransactionID is generated by FE; middleware only passes it through!

// ✅ FE code - Generate new Transaction ID
const postBookingTxnId = crypto.randomUUID().replace(/-/g, '');  // Generated by FE

await fetch('/middleware/polarhub/order/retrieve', {
  body: JSON.stringify({ transactionId: postBookingTxnId, orderId })
});
await fetch('/middleware/polarhub/seat-availability', {
  body: JSON.stringify({ transactionId: postBookingTxnId, ... })  // Reuse
});

// ❌ Do not generate in middleware
const postBookingTxnId = generateTransactionId();  // Strictly prohibited!
```

## Response Structure

```typescript
interface OrderRetrieveResponse {
  Order: {
    OrderID: string;
    Owner: string;
    OrderStatus: 'HELD' | 'TICKETED' | 'CANCELLED';
    BookingRef: Array<{
      AirlineID: string;
      ID: string;          // PNR
    }>;
    OrderItem: Array<{
      OrderItemID: string;
      FlightRef: string[];
      PaxRefID: string[];
      Price: {
        TotalAmount: { Amount: number; CurrencyCode: string };
      };
    }>;
    PaxList: Array<{
      PaxID: string;
      Ptc: string;
      Individual: {
        NameTitle: string;
        GivenName: string[];
        Surname: string;
      };
    }>;
    TicketDocInfo?: Array<{  // Only after ticketing
      TicketDocNbr: string;
      Type: string;
      CouponInfo: Array<{
        CouponNumber: string;
        CouponStatus: string;
      }>;
    }>;
  };
  // OCN information (involuntary changes)
  OrderChangeNotice?: {
    ChangeType: string;       // SCHEDULE_CHANGE, CANCELLATION
    OriginalFlight: { ... };
    AlternativeFlight?: { ... };
  };
}
```

## Workflows Based on Order Status

### HELD Status
```typescript
if (response.Order.OrderStatus === 'HELD') {
  // Available actions:
  // - WF_HELD_SEAT: Seat change
  // - WF_HELD_SERVICE: Service addition
  // - WF_HELD_CONFIRM: Ticketing (PaymentList required)
  // - WF_HELD_CANCEL: Cancellation
  // - WF_HELD_ITIN: Itinerary change
  // - WF_HELD_PAX: Passenger info change
  // - WF_HELD_SPLIT: PNR split
}
```

### TICKETED Status
```typescript
if (response.Order.OrderStatus === 'TICKETED') {
  // Available actions:
  // - WF_TKT_SEAT: Seat change (OrderQuote required)
  // - WF_TKT_SERVICE: Service addition (OrderQuote required)
  // - WF_TKT_VOLCHANGE: Itinerary change
  // - WF_TKT_REFUND: Refund
  // - WF_TKT_OCN: OCN acceptance (when OrderChangeNotice exists)
}
```

### OCN (Involuntary Change) Check
```typescript
if (response.OrderChangeNotice) {
  // OCN acceptance workflow (WF_TKT_OCN)
  const { ChangeType, AlternativeFlight } = response.OrderChangeNotice;
  // Accept via OrderChange AcceptChange
}
```

## DTO Structure (NestJS)

```typescript
/**
 * OrderRetrieve Request DTO
 * POST-BOOKING flow: OrderRetrieve is the starting point
 * TransactionID is provided by FE (pass-through principle)
 */
export class OrderRetrieveRequestDto {
  @ApiProperty({
    description: 'Transaction ID for post-booking session (generated by FE)',
    example: '4ba5a0b50d2c45b3b5eb343b57ba8897',
  })
  @IsString()
  @Matches(/^[0-9a-f]{32}$/i)
  transactionId: string;

  @ApiProperty({
    description: 'Order ID to retrieve (returned from OrderCreate response)',
    example: 'ORD-SQ-12345678',
  })
  @IsString()
  orderId: string;
}

/**
 * OrderCancel Request DTO
 * POST method - orderId is in body, not URL path
 */
export class OrderCancelRequestDto {
  @IsString()
  @Matches(/^[0-9a-f]{32}$/i)
  transactionId: string;

  @IsString()
  orderId: string;
}
```

## Determining Next Steps

```typescript
// Determine next API after OrderRetrieve
function getNextStep(response: OrderRetrieveResponse, action: string) {
  const status = response.Order.OrderStatus;

  if (action === 'changeSeat') {
    return status === 'HELD' ? 'SeatAvailability' : 'SeatAvailability → OrderQuote';
  }
  if (action === 'addService') {
    return 'ServiceList → OrderQuote';
  }
  if (action === 'confirm' && status === 'HELD') {
    return 'OrderChange (PaymentList)';
  }
  if (action === 'cancel') {
    return status === 'HELD' ? 'OrderCancel' : 'OrderReshop → OrderCancel';
  }
  if (action === 'changeItinerary') {
    return 'OrderReshop';
  }
  if (action === 'acceptOCN' && response.OrderChangeNotice) {
    return 'OrderChange (AcceptChange)';
  }
}
```

## Important Notes

### Transaction ID Management (Pass-through Principle)
```typescript
// Generated by FE; middleware only passes through!
// FE generates a new Transaction ID when starting Post-Booking
// Separate from the Prime Booking Transaction ID

// ✅ FE responsibility - Reuse within the same Post-Booking session
const txn = crypto.randomUUID().replace(/-/g, '');  // Generated by FE
OrderRetrieve(txn) → ServiceList(txn) → OrderQuote(txn) → OrderChange(txn)

// ❌ Do not generate in middleware
const txn = generateTransactionId();  // Strictly prohibited!
```

### PNR Extraction
```typescript
// Extract PNR from response
const pnr = response.Order.BookingRef.find(
  ref => ref.AirlineID === response.Order.Owner
)?.ID;
```
